# OpenQuestions.md

## 1. 使用说明

本文件集中列出当前规则中仍然可能需要设计者确认的歧义点。

MVP 实现时可以按照 `Docs/Rules.md` 中的默认建议执行。设计者确认后，应同步修改：

- `Docs/Rules.md`
- `Docs/TechnicalSpec.md` 中相关数据结构或说明
- `Docs/Tasks.md` 中相关任务要求

## 2. 规则待确认清单

### Q1. 邻接规则

当前默认：四方向邻接。

待确认：是否永远使用四方向，还是某些单位/地形会使用八方向？

最终决定：

```text
永远使用四方向
```

### Q2. 地形是否影响气

当前默认：地形不影响气。

待确认：山峦、河流、森林等空格是否都能提供气？

最终决定：

```text
根据地形而定，无法落子的地形如山峦和河流不能提供气。
```

### Q3. 是否允许在敌方占有地块落子

当前默认：允许，只要该格可放置且没有棋子。

待确认：是否需要限制玩家只能在己方控制区、无归属区或一定距离内落子？

最终决定：

```text
允许
```

### Q4. 远距离落子规则

当前默认：允许远距离落子，但费用与最近友方棋子的曼哈顿距离成正比。

待确认：是否设置最大距离，或改用路径距离？

最终决定：

```text
不设置最大距离，不该用路径距离
```

### Q5. 当前方没有任何棋子时如何落子

当前默认：只能在关卡指定出生点落子。

待确认：无棋子是否意味着失败？是否允许重生？

最终决定：

```text
在一局游戏开始时玩家若无法在关卡指定出生点落子则无法进行后续游戏
```

### Q6. 提子结算顺序

当前默认：先提敌方，再检查己方。

待确认：是否需要实现同时结算？

最终决定：

```text
先提敌方，再检查己方
```

### Q7. 是否允许自杀手

当前默认：不允许纯自杀手；允许提子后获得气的落子。

待确认：是否允许为了战术目的牺牲己方棋块？

最终决定：

```text
不允许
```

### Q8. 是否实现打劫规则

当前默认：MVP 不实现。

待确认：是否要禁止重复棋盘状态？

最终决定：

```text
暂不需要
```

### Q9. 占地是否受地形阻挡

当前默认：不受阻挡。

待确认：山峦、河流是否阻挡控制范围？

最终决定：

```text
阻挡
```

### Q10. 棋子所在格是否必定归属己方

当前默认：不做特殊处理，仍可能因双方控制而变成争夺。

待确认：是否需要让棋子脚下格永远归属己方？

最终决定：

```text
是的
```

### Q11. 初始资源

当前默认：双方 `Food = 5`，`Iron = 0`。

待确认：是否每关不同？是否需要全局默认？

最终决定：

```text
每关不同
```

当前默认：`FoodCost = 1 + d`。

```text
暂不需要
```

当前默认：强化只增加占地控制半径，不影响气。

待确认：强化是否应增加生存能力、气、提子能力或特殊技能？

当前默认：`Food = 2`，`Iron = 1`。

```text

```

### Q15. 完整回合数增加时机

当前默认：白方结束回合后完整回合数 +1。

待确认：是否黑方开始时 +1，或每方行动都计半回合？

最终决定：

```text
白方结束回合后完整回合数 +1
```

### Q16. 是否允许空过

当前默认：每回合至少一个有效操作，除非没有合法操作。

待确认：玩家是否可以主动跳过？跳过是否有惩罚？

最终决定：

```text
不允许空过
```

### Q17. 传统占地平局处理

待确认：是否需要黑方优势、白方优势、资源比较或棋子数量比较？

最终决定：

```text
平局黑胜
```

### Q18. 夺旗超时处理

当前默认：超时后按传统占地数量结算。

待确认：是否超时即失败、平局或按资源结算？

最终决定：

```text
超时即失败
```

当前默认：不可放置，但可控制、可产出、可提供气。
